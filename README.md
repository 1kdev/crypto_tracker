# 🚀 Crypto Alert Bot

Telegram-бот для отслеживания цен на криптовалюту и получения персональных уведомлений. Бот получает актуальные данные через публичный API Binance и позволяет каждому пользователю самостоятельно управлять своим списком тикеров.

## 🛠 Tech Stack

* Python 3.10+
* aiogram 3.x — асинхронный фреймворк для Telegram-ботов
* aiosqlite — работа с базой данных SQLite
* Binance API — получение актуальных цен криптовалют
* python-dotenv — загрузка переменных окружения

## ⚙️ Как запустить у себя

### 1. Скачай проект

```bash
git clone https://github.com/1kdev/crypto_tracker.git
cd crypto_tracker
```

### 2. Создай виртуальное окружение

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установи зависимости

```bash
pip install "aiogram<4.0" python-dotenv aiosqlite pydantic-settings
```

### 4. Настрой Telegram-бота

Создай файл `.env` в корневой папке проекта:

```env
BOT_TOKEN=твой_токен_от_BotFather
```

### 5. Запусти бота

```bash
python app.py
```

База данных SQLite создаётся автоматически при первом запуске.

## ✅ Что работает в версии 1.4

### 💼 Мои тикеры

Пользователь видит свои тикеры через интерактивное inline-меню.

Для каждого тикера доступны отдельные действия:

* 📊 просмотр тикера и текущей цены
* ✏️ изменение тикера
* ❌ удаление тикера
* 🔔 настройка уведомлений
* ↩️ возврат назад

Все тикеры хранятся отдельно для каждого пользователя.

### ➕ Добавление тикеров

Пользователь может добавить торговую пару, например:

```text
BTC/USDT
BTCUSDT
ETH/USDT
ETHUSDT
```

Бот проверяет существование пары и не позволяет добавить один и тот же тикер повторно.

### ✏️ Изменение и удаление

Тикеры можно изменить или удалить непосредственно через интерактивное меню.

Все действия выполняются для конкретного пользователя и не затрагивают тикеры других пользователей.

### 🔔 Уведомления

Для каждого тикера можно настроить персональные уведомления.

Доступны интервалы:

* 5 минут
* 15 минут
* 30 минут
* 45 минут
* 60 минут

Также можно настроить уведомление при изменении цены.

Доступные значения:

* 0.5%
* 1%
* 2%
* 3%
* 5%
* 10%
* собственное значение в процентах

### 📈 Автоматические обновления

Бот автоматически отправляет пользователю актуальную цену отслеживаемых тикеров согласно настроенным уведомлениям.

Также предусмотрены автоматические часовые обновления цены.

### 🗄 База данных

Используется SQLite.

В базе хранятся:

* пользователи Telegram
* тикеры пользователей
* настройки уведомлений
* данные, необходимые для контроля изменений цены

Отдельный сервер базы данных не требуется.

### 🔐 Разделение пользователей

Каждый пользователь работает только со своими тикерами и настройками уведомлений.

Операции добавления, изменения, удаления и настройки алертов привязаны к Telegram ID пользователя.
